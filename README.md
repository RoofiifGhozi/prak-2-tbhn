# Praktikum 2 PAPB

Project Praktikum Pengembangan Aplikasi Perangkat Bergerak (PAPB) - Modul 2: Activity Lifecycle, Composable Layout, dan Modifier.

## Struktur Tugas
- `ProfilMahasiswa.kt`: Komponen profil mahasiswa dengan avatar icon bulat Cyan dan layout Row/Column.
- `HalamanUtama.kt`: Halaman utama yang menggabungkan profil mahasiswa dan intent WhatsApp dengan layout vertikal Column.
- `MainActivity.kt`: Activity launcher dengan implementasi callback siklus hidup (Activity Lifecycle).
